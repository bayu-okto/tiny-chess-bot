A chess engine in at most 4 KB of Python (3,675 bytes). 0x88 board, negamax alpha-beta with quiescence search, transposition table, killer moves, MVV-LVA move ordering, and late move reductions. Practice Elo 1,191 on the make.fun gauntlet — clears the 1,154 final floor.

## Run it

```sh
python3 main.py
```
